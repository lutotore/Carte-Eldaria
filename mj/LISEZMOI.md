# Dossier du MJ

Ce dossier n'est **jamais versionné** (voir `.gitignore`), sauf ce fichier.

Depuis le portail en ligne, **la référence est la base du serveur** : la table du MJ y lit et y écrit directement.
Ce dossier ne sert plus qu'à deux choses :

- garder le fichier `etat.json` de départ, à importer une fois sur le serveur (voir `DEPLOIEMENT.md`, étape 7)
  ou dans ta base de développement (voir `README.md`) ;
- ranger les copies du monde que tu rapatries du serveur (`exporter-etat`).

**Garde aussi une copie ailleurs** (cloud perso, clé USB) : ces fichiers contiennent tous les secrets de la campagne.

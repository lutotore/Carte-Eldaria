# Dossier du MJ

Ce dossier n'est **jamais versionné** (voir `.gitignore`), sauf ce fichier.

Place ici `etat.json`, l'état complet de ta campagne : Horloge d'Éveil, croyances,
réputations, îles cachées, missions secrètes, notes. La table du MJ (`npm run mj`)
le lit et le réécrit à chaque action.

**Sauvegarde-le ailleurs** (cloud perso, clé USB) : s'il est perdu, il n'existe nulle part ailleurs.
